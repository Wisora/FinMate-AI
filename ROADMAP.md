# FinMate AI Roadmap

This roadmap outlines upcoming features, improvements, and priorities for FinMate AI.  
It is designed to guide contributors and maintainers toward building a polished, client‑ready finance assistant.

---

## ✅ Completed

- Goals management (add, update, delete)
- Reports service (weekly/monthly with dynamic inputs)
- Recommendations service (AI tips)
- Assistant chat integration
- Accessibility improvements (ARIA labels, dark mode)
- Repo hygiene: README, CONTRIBUTING, CODE_OF_CONDUCT, LICENSE

---

## 🚧 In Progress

- Authentication service (`authService.js`) integration
- CI/CD pipeline with GitHub Actions
- Hosting setup (Netlify/Vercel/Azure)
- Mobile responsiveness polish
- Translation improvements for multilingual support

---

## 📅 Upcoming Features

- 🔐 **Authentication**
  - Firebase/Supabase login
  - Profile management with avatars
- 💳 **Subscription Flow**
  - Free vs Pro plan handling
  - Payment integration (Stripe/PayPal)
- 📱 **Mobile Optimizations**
  - Responsive layouts for small screens
  - Touch‑friendly UI components
- 📊 **Analytics**
  - Usage tracking
  - Report generation metrics
- 🧩 **Integrations**
  - Budget import/export
  - API hooks for external finance data

---

## 🛠 Technical Improvements

- Add unit tests for services (`goalsService`, `reportsService`)
- Improve error handling for async calls
- Implement caching for recommendations
- Optimize build with Vite chunk splitting
- Lighthouse audits for performance & accessibility

---

## 🤝 Contributor Opportunities

- Create new UI components (charts, progress bars)
- Expand translations
- Write documentation for onboarding
- Add test coverage for forms and services

---

## 📌 Long‑Term Vision

- AI‑powered financial forecasting
- Multi‑currency support
- Secure cloud sync for user data
- Community plugin system for custom reports
