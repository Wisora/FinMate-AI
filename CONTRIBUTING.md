# 🤝 Contributing Guide

Thank you for your interest in contributing!  
This project is maintained with the help of automated AI Ops agents, but human contributions are always welcome.

---

## 📦 Getting Started

1. Fork the repository
2. Clone your fork locally
3. Install dependencies:

   ```bash
   npm install

4.Run tests and lint before committing:
npm test
npm run lint

📝 Commit Guidelines
We follow Conventional Commits for clarity and automation:

feat: → new feature

fix: → bug fix

docs: → documentation changes

style: → formatting, no code changes

refactor: → code restructuring

test: → adding or updating tests

chore: → maintenance tasks

Examples:

feat: add weekly budget report

fix: resolve login error

docs: update README with badges

🔄 Pull Requests
Use the provided PR template (.github/PULL_REQUEST_TEMPLATE.md)

Ensure all checks pass (tests, lint, accessibility)

Link related issues (Fixes #123)

Add screenshots or demo links if UI changes are involved

✅ Quality Standards
Code must build without errors

Tests must pass locally

Accessibility verified (ARIA labels, Lighthouse audit)

No secrets or .env files committed

Documentation updated when needed

🛡 Security
Run npm audit before submitting

Report vulnerabilities via GitHub Security tab

📊 Release Process
Use semantic versioning (vX.Y.Z)

Tag releases with vX.Y.Z to trigger automated release notes

Changelog is auto‑generated by AI Ops Suite
